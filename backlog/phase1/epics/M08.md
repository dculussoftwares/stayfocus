title: "Remote controls"
---

The parent controls the linked child phone. Commands are plain Firestore writes, and the child's always-on foreground service picks them up with a realtime listener, so **no server is involved**. The child reports status every 1–2 minutes and on change; enforces parent blocks, per-app locks and focus sessions; and sends unlock requests and tamper alerts. The only server piece is one Firestore-triggered function, `notifyParent`, which sends push notifications to the parent (sending FCM needs server credentials that can't ship in an app). It's deployed via Terraform from GitHub Actions.

**Exit criteria:** on dev, a parent command reaches an online child phone in < 5 s; requests and alerts reach the parent as push notifications in < 10 s; all writes are covered by rules tests.
