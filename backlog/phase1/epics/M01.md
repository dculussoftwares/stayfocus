---

Set up everything later milestones build on: the Gradle multi-module project for both apps, CI and code quality, design tokens and the shared Compose components (including the rotary dial, gauge and LED charts), navigation with 4 tabs and sub-screens, the domain model, the Room schema and DataStore. Also lays the infrastructure-as-code base: GitHub repo settings and the GCP/Firebase Terraform pipeline (HCP Terraform state, applied only from GitHub Actions).

Includes the full quality pipeline: pre-commit/pre-push hooks, CI (static analysis, unit tests with coverage, screenshot tests, build, one aggregate `ci-pass` check), instrumented + Maestro end-to-end tests, and security/supply-chain scanning.

**Exit criteria:** both apps build and launch on API 26 and API 36 with the themed 4-tab shell; CI (`ci-pass`), pre-commit hooks, E2E smoke flows and security scans run and are required on `main`; `infra/firebase` plans and applies the dev environment from GitHub Actions.
