title: "Linking"
---

Parent → child linking. The Kids app shows a QR code with a one-time token (5-minute TTL); the parent scans it with CameraX + ML Kit; both phones show the same 6-digit code; the child taps Allow; a device doc is created under the parent.

**Backend approach (plan §9):** Firebase client SDKs + Firestore security rules + App Check by default. Cloud Functions are used only where security or clean architecture needs them: the cross-account link handshake (`claimLinkToken`, `approveLink`) and complete deletion on unlink (`unlinkDevice`). Firestore, rules, App Check and Functions are provisioned and deployed **only via Terraform from GitHub Actions**. Includes the Kids app shell and its Play-compliance basics (IsMonitoringTool, `specialUse` FGS, persistent notification).

**Exit criteria:** a parent links a child phone end to end on dev; either side can unlink; security rules and Functions are tested against the emulators in CI; App Check is enforced on Firestore and the callables.
