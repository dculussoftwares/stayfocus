## Context
V5_SPEC §4 rows `PillButton` … `AppIconTile`. Inspect the prototype markup for each (button styles throughout; toggle line 177; segmented 160–162; day chips 312; tags 257, 261, 355, 362; online pill 196; app tiles 175, 241, 281).

## Scope
- `PillButton` with variants `Primary`, `White`, `Orange` (gradient + grain), `Glass`, `Secondary`, `Text` (optional underline); sizes 62/60/50/46/44; leading icon slot; `loading` (spinner + label); disabled alpha.
- `RoundIconButton` (46 dp white circle; optional red badge with white border; dark glass variant).
- `V5TextField` (h58, r24, white, placeholder, password show/hide, error text slot).
- `V5Toggle` (52 × 32, 150 ms knob animation, `Role.Switch`, state description).
- `SegmentedPill` (ink container or glass-on-gradient; any number of equal-width options; selected white/ink), with `Role.Tab` semantics.
- `DayChips` (M T W T F S S; refuses to turn off the last day).
- `Tag` variants: `TargetTag` (red, dot), `StatusTag` (red "Protection off", orange "Request", orange "AI draft" with sparkle), `OnlinePill` (pulse dot; white-on-pink variant; offline variant).
- `AppIconTile(pkg, size)` (reuses the shipped launcher-icon loader; clip r ≈ .34 × size; letter fallback on the brand/hashed colour, V5_SPEC §3) and `AppIconStack(pkgs, size)` (overlap −8 dp, 2 dp white border, max 3).

## Acceptance criteria
- [ ] Each component has `@Preview`s for every variant/state and a Roborazzi test.
- [ ] Touch targets ≥ 48 dp even where the visual is smaller (toggle, day chip, tags that are buttons).
- [ ] TalkBack: buttons announce label + state; toggle and segmented expose role and selection.
- [ ] Only `V5Theme` tokens are used.
