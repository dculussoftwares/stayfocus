## Scope
- `google_firebase_project`, and `google_firebase_android_app` for `com.dculus.stayfocused` and `com.dculus.stayfocused.kids` with debug and release SHA-1/SHA-256 fingerprints passed in as variables.
- Identity Platform / Firebase Auth config via `google_identity_platform_config`: email/password enabled, anonymous enabled (for Kids), and the Google provider (`google_identity_platform_default_supported_idp_config`). **Research and document** how the OAuth web client ID is obtained without the console (an IAP/OAuth client resource, or the Firebase-created client read back with a data source). If a gap can't be closed in Terraform, document it in `docs/INFRASTRUCTURE.md` and flag it in the PR for a decision. Don't click in the console.
- Output `google-services.json` via the `google_firebase_android_app_config` data source. CI (`ci.yml`, an optional job) writes it into `app/` and `kids/` for Firebase-enabled builds. The file is never committed.
- A budget alert (`google_billing_budget`) on the dev project.

## Acceptance criteria
- [ ] Apply from Actions creates both Android apps and enables the auth providers; the plan on `main` afterwards is clean.
- [ ] A Firebase-enabled CI build downloads its config from the Terraform output and signs in with an emulator test account.
