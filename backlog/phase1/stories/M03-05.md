## Scope
- Day stepper from today back to −6. Labels Today / Yesterday / weekday name; date "06 OCT"; next is disabled at today (opacity .3).
- Metric tabs: Screen time / Opens / Unlocks; big total + "- - - AVG …".
- 24×10 LED chart with the average line.
- Ranked app list (rank 01…, icon, name, value, bar) sorted by the metric. On Unlocks, rank by "first app opened after unlock" (M3-01).

## Acceptance criteria
- [ ] Unit tests for ranking and the day labels; screenshot tests for each metric.
- [ ] Days with no data show a clear empty state instead of zeros everywhere.
