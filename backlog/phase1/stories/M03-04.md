## Context
Prototype: the "Home" flow. Status and actions are separate (UX principle).

## Scope
- Header: date (mono uppercase), greeting with the account's first name (or no name when there's no account), avatar initial → Account.
- Action row: "+ New block" (white, primary) → wizard with target "This phone"; "AI Describe" → Block tab with the AI box open.
- Gauge card: today's total vs the 4 h scale, average marker, mini LED bars 24×5, and 3 stats: launches / unlocks / blocked.
- Take a break card from M2-05.
- Active blocks for this phone: rows with type chip, name, description and toggle (→ `BlockRepository.setEnabled`).
- Linked phones strip using a `LinkedDevicesRepository` (empty fake until M7-10), with an empty state that leads to Devices.
- Usage access not granted → the gauge card shows an "Allow usage access" state that opens the settings intent.
- Tapping the gauge → Insights.
