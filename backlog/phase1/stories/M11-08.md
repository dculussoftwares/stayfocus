## Context
The prototype draws simple 24 px stroke icons inline (back, close, plus, bell, arrow, sparkle, block circle, lock, timer, check) and some art: `breakArt` (544), `linkArt` (546), `pulseGreen` (550), `scanLine` (551) + the corner brackets (391–395), `spinner` (542), `sparkle` (543).

## Scope
- `V5Icons`: `ImageVector`s converted from the prototype SVG paths (stroke widths as drawn: 1.8–2.6). Don't add an icon font.
- `BreakArt(lengthMins)`: 23 ticks (centre tick 3 × 34 lime, others 2 × 13/20 white with alpha fading from the centre) + `DotMatrixText` minutes + "min".
- `LinkArt`: two phone outlines with 3 × 3 dots, dashed arc with moving dash (1.1 s), blinking lime dot (1.6 s).
- `PulseDot(color)` (1.8 s ring), `Spinner` (18 dp, .8 s), `ScanFrame` (260 dp, 4 corner brackets 44 dp / 3 dp / r22 + moving scan line with pink glow, 2.4 s).
- All animations use the M11-07 motion helper (static when animations are off).

## Acceptance criteria
- [ ] Icons render identically to the prototype at 18–24 dp (Roborazzi sheet of all icons).
- [ ] Art previews + Roborazzi (static frame) match `05-home.png` (break art), `17-family.png` (link art), `19-scan-code.png` (brackets).
- [ ] Decorative art is hidden from TalkBack.
