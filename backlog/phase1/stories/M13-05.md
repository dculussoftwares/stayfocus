## Context
V5_SPEC §7. Shipped states that v5 doesn't draw.

## Scope
- Sign-in gate before linking ("Sign in to\nlink a phone"), camera permission / denied / unavailable states on the dark scan screen, link waiting-for-child, declined, expired, used and network-error states on the Codes match screen.
- Family: "This phone" row, empty state, "Offline for a while" and "Phone was unlinked" alerts.
- Child's phone: per-app lock list (`V5Toggle` rows), focus length choice 25/50/90 (long-press or a small `SegmentedPill` on the Focus tile), multiple pending requests/alerts.

## Acceptance criteria
- [ ] Every extra listed in Scope still works as before (existing tests pass; Maestro flows that use it pass).
- [ ] Built only from `core.ui.v5` components and tokens; shipped copy unchanged unless the PR asks a maintainer to approve a change.
- [ ] No v5-extra marker for this area is left (`grep -rn "v5-extra: <this id>" --include=*.kt .` is empty; the backlog files mention the marker too).
- [ ] PR shows a screenshot of each restyled state and asks for design sign-off; Roborazzi baselines re-recorded.
