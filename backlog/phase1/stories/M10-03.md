## Scope
- Release signing from GitHub Actions secrets (upload key), R8 rules (Firebase, kotlinx.serialization, Room, ML Kit), and the versionCode scheme.
- `release.yml` on tag `v*`: build `bundleRelease` for both apps, attach the AABs to a GitHub Release, and optionally upload to the Play internal track (gradle-play-publisher with a Play service account; the Play account itself is created by a human).
- Release builds use the **prod** Firebase config from Terraform outputs (M10-04).

## Acceptance criteria
- [ ] A tag produces signed AABs that install via bundletool on a device.
