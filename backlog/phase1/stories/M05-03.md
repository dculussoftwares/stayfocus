## Scope
- `PermissionsRepository.observe(): Flow<Permissions>`, refreshed on `ON_RESUME`: usage (AppOps), accessibility (`AccessibilityStatus`), overlay (`Settings.canDrawOverlays`), notifications (runtime `POST_NOTIFICATIONS` on 33+, `areNotificationsEnabled`). Battery optimisation (`isIgnoringBatteryOptimizations`) as a fifth, non-gating item.
- An intent helper per permission: `ACTION_USAGE_ACCESS_SETTINGS`, `ACTION_ACCESSIBILITY_SETTINGS`, `ACTION_MANAGE_OVERLAY_PERMISSION` + package URI, the notification runtime request, and `ACTION_IGNORE_BATTERY_OPTIMIZATION_SETTINGS`. **Don't** use `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` (Play-restricted).
- Android 13+ restricted settings: detect sideloaded installs and show guidance ("App info → ⋮ → Allow restricted settings") before opening Accessibility.
