## Scope
- `google_firestore_database` (native mode, dev region), a TTL policy on `linkTokens.expiresAt` (`google_firestore_field` with `ttl_config`), and the composite indexes needed by M7/M8 queries (`google_firestore_index`).
- Rules deployed from `firebase/firestore.rules` via `google_firebaserules_ruleset` + `google_firebaserules_release`, so a rules change in a PR is planned and applied by Actions.
- **App Check** for both Android apps: Play Integrity (`google_firebase_app_check_play_integrity_config`) and debug tokens for dev/CI (`google_firebase_app_check_debug_token`, values from GitHub secrets). Enforcement on Firestore via `google_firebase_app_check_service_config` (`firestore.googleapis.com`, `ENFORCED` on dev once the M6-02 clients send tokens; a variable switches it to `UNENFORCED` for a rollout period).

## Acceptance criteria
- [ ] A rules-file change shows as a ruleset diff in the PR plan and goes live on merge.
- [ ] A Firestore request from a build without a valid App Check token is rejected on dev.
