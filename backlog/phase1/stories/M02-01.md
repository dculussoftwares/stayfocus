## Context
A single pure function decides whether an app may be in the foreground. It's the most test-critical code in the project, so write it test-first.

## Scope
- `RuleEvaluator.evaluate(ctx: EvaluationContext): Decision`.
  - `EvaluationContext(now: ZonedDateTime, pkg, blocks: List<Block>, lockedApps, breakSession?, focusSession?, allowances: List<TemporaryAllowance>, usage: Map<pkg, AppUsageSnapshot(todayMs, thisHourMs)>, cycleStates: Map<(blockId,pkg), CycleState>, allowlist: Set<pkg>)`.
  - `Decision = Allow | Block(reason: BlockReason, blockId: String?, until: Instant?)`, with `BlockReason ∈ {BREAK, FOCUS, NOW, LIMIT_DAILY, LIMIT_HOURLY, CYCLE_REST, SCHEDULE, MANUAL_LOCK}`.
- Rules:
  - The allowlist always wins. A valid `TemporaryAllowance` for the pkg allows it (parent-approved extra time).
  - BREAK/FOCUS block every non-allowlisted app until `endsAt`.
  - NOW: `startedAt ≤ now < startedAt + duration` and pkg in apps.
  - LIMIT: the day applies and the **combined** usage of all the block's apps (today, or this clock hour) is ≥ limit → until the next midnight / next hour.
  - SCHEDULE: active if `now` falls in the range on an applicable day. For overnight ranges the day is the start day (Mon 22:00–Tue 07:00 belongs to Monday) → until the range end.
  - CYCLE: block while `lockedUntil > now`.
  - MANUAL_LOCK: indefinite (`until = null`).
  - Disabled blocks are ignored. With several matches, return the one with the latest `until` (`null` counts as the latest).
- `CycleStateMachine.advance(state, foregroundDeltaMs, now, block)`: adds foreground time; once `used ≥ use`, sets `lockedUntil = now + rest` and `used = 0`; the next open after `lockedUntil` starts a fresh window (foreground time only; plan §1).
- `nextEvaluationAt(ctx): Instant?`: the earliest moment the decision could change (limit exhaustion at current usage, schedule start/end, NOW end, break end, cycle exhaustion or unlock, allowance expiry).

## Acceptance criteria
- [ ] ≥ 40 table-driven tests covering each reason, precedence, disabled blocks, empty days, an overnight schedule across Sunday→Monday, hourly reset, a DST transition, and allowance overriding a limit.
- [ ] 100% line coverage for the evaluator and the cycle state machine (Kover report).
- [ ] No Android imports in the evaluator package.
