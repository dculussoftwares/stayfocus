## Scope
- 4 rows (LED, title, 1-line reason, Allow/On). Copy: Usage access / "Shows screen time and knows when limits are reached.", Accessibility / "Notices when a blocked app opens.", Display over apps / "Shows the block screen on top.", Notifications / "Breaks, limits and requests."
- A segmented progress bar x/4. CTA "All set · Continue" (lime) or "Continue for now" (dark). Continuing with < 4 shows the toast "Blocking needs all 4. Finish in Account."
- Sets `onboardingComplete`; the start destination is now Home.
- Tapping Accessibility opens the disclosure (M5-05) and never goes straight to Settings.
