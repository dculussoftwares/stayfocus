## Context
v5 sets durations by dragging a ruler of ticks (`ruler()`, prototype line 566; wizard 295–301, break sheet 476–478). It replaces the v2 `RotaryDial` on migrated screens.

## Scope
- `:core:model` `RulerScale(min, max, step)`: `valueAt(fraction)` = round((min + f·(max−min))/step)·step clamped to [min, max]; `fractionOf(value)`; `ticks(value, n = 44)` → 45 tick states (current index = round(p·44); `Passed` before it, `Ahead` after). Test-first, including boundaries and the 4 ranges in V5_SPEC §5 (5–240/5, 1–60/1, 5–180/5, 15–480/15) and the break range 5–120/5.
- `:core:ui` `TickRuler(value, onValueChange, scale, colors)`: 72 dp tall, ticks bottom-aligned and spread evenly; current 4 × 70, passed 2 × 46, ahead 2 × 26, r2; per-state colour and alpha (white set for gradient cards; break-sheet set: passed orange, ahead `#C9CBCF` @ .5, current ink). Tap or drag anywhere sets the value (pointer x / width); a haptic tick when the value changes.
- Accessibility: slider semantics (`progressBarRangeInfo` with steps, `setProgress`), and volume-key style increments by one step; the caller supplies the spoken value.
- Optional `RulerLabels(min, max)` row ("{min}", "Drag to set", "{max}") using the shared duration formatter.
