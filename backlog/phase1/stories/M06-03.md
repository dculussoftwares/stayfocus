## Scope
- A real `AuthRepository`: sign in, create, sign out, `currentUser` flow, `sendPasswordResetEmail` with the toast "Reset link sent to {email}".
- Map Firebase errors to inline copy (wrong credentials, email already in use, weak password, network).
- On first sign-in, create `users/{uid}` (`displayName`, `email`, `createdAt`). Wait for M7-03 rules; until then use the emulator.

## Acceptance criteria
- [ ] Tests run against the Firebase Auth emulator in CI.
- [ ] The session persists across restarts.
