## Scope
- `BlockingEngine` (singleton, scoped to the accessibility service lifecycle). It combines the foreground app, enabled blocks, locked apps, break/focus, allowances, cycle states and an `AppUsageProvider` interface. It evaluates on every foreground change and again at `nextEvaluationAt` (a coroutine timer, re-armed after each evaluation; at least every 30 s while a tracked app is in front).
- On `Block` → `BlockScreenLauncher.show`, and record a `BlockEventEntity` (feeds the "blocked" stat on Home).
- Track foreground sessions (start/stop timestamps) and feed the deltas to the `CycleStateMachine`, persisting via the DAO.
- A temporary `AppUsageProvider` that uses the engine's own foreground timing (it's replaced/augmented by UsageStats in M2-06).
- `BlockAllowlistProvider`: own package(s), default launcher(s), default dialer (`TelecomManager.defaultDialerPackage`), default SMS app, Settings, system UI.

## Acceptance criteria
- [ ] An integration test (Robolectric) with fake foreground events and a `TestClock` drives the engine through a NOW block start→end.
- [ ] No coroutine leaks: the engine scope is cancelled in `onDestroy`/`onUnbind`.
- [ ] Re-arming the timer is unit-tested (a schedule boundary while the app stays open triggers a block).
