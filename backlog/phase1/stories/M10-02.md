## Scope
- A Gradle verification task (or unit test on the merged manifests) run in CI that asserts:
  - no `QUERY_ALL_PACKAGES`, no `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`;
  - no `isAccessibilityTool`;
  - `:kids` has IsMonitoringTool + the FGS `specialUse` property;
  - `:app` has no FGS;
  - `targetSdk = 36`.
- The handoff's section-8 checklist, mirrored in `docs/play/COMPLIANCE.md` with links to the code.

## Acceptance criteria
- [ ] CI fails if a forbidden permission is added (shown by a test).
