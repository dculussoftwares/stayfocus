## Context
A Play prominent-disclosure requirement: a separate in-app disclosure right before Settings, with an explicit "Agree" tap.

## Scope
- Sheet with "What it reads / Why / Never" sections, copied exactly from the prototype; "Agree and open Settings" / "No thanks".
- Only "Agree" opens Settings and stores `accessibilityConsentAt`. "No thanks" closes and leaves the row as Allow.
- A reusable `AccessibilityDisclosure` composable (the Kids app reuses it with kids copy in M7-04).

## Acceptance criteria
- [ ] UI test: "No thanks" never fires the Settings intent.
- [ ] The text matches the accessibility service description string (M2-02).
