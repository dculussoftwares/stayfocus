## Scope
- Header: online LED, battery, "USING {APP}", today's total.
- Tamper alert card (red, Remind / Dismiss): Remind → `REMIND_PERMISSION`; Dismiss → alert `dismissed`.
- Unlock request card (amber, 15m / 30m / 1h / No) → M8-05.
- Focus session card (25 / 50 / 90 min; while running, a countdown + stop).
- Blocks on this phone (rows with toggles) + "New block for {name}" → wizard with that target.
- Per-app lock toggles with usage bars (red when blocked) → commands, toast "{app} locked on {device}" / "unlocked".
- Unlink → `unlinkDevice`.

## Acceptance criteria
- [ ] Every control round-trips to a real child phone on dev (screen recording).
- [ ] Screenshot tests for each card state.
