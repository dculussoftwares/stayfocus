## Scope
- `/web` static site: `privacy.html` (draft content; finalised in M10-01) and `delete-account.html` (sign in with the Firebase JS SDK, Google or email, then call `deleteAccount`; it also explains what gets deleted).
- GitHub Pages enabled **through Terraform** (the `github_repository` `pages` block in `infra/github`), deployed by a `pages.yml` workflow (`actions/deploy-pages`).
- The Firebase web app config comes from Terraform (`google_firebase_web_app` + config data source in `infra/firebase`), injected at build time.

## Acceptance criteria
- [ ] Both pages are live at the Pages URL; account deletion works from the web on dev.
- [ ] The URLs are referenced in the app (M6-05) and in `docs/play/` (M10-01).
