## Context
Nothing exists yet. Every later story assumes the module layout, convention plugins and version catalog from this story. See `docs/IMPLEMENTATION_PLAN.md` §1 and §2.

## Scope
- Gradle wrapper (latest stable), `settings.gradle.kts` including every module in plan §2: `:app`, `:kids`, `:core:model`, `:core:ui`, `:core:data`, `:core:usage`, `:core:blocking`, `:core:sync`, `:core:testing`, `:feature:onboarding`, `:feature:home`, `:feature:block`, `:feature:devices`, `:feature:insights`, `:feature:account`.
- `gradle/libs.versions.toml` with AGP, Kotlin, KSP, Compose BOM, Material 3, Hilt, Room, DataStore, Navigation Compose, kotlinx-serialization, coroutines, Timber, Coil, and test libs (JUnit4, Turbine, MockK, Robolectric, Roborazzi, Compose UI test).
- `build-logic/` convention plugins: `stayfocused.android.application`, `stayfocused.android.application.compose`, `stayfocused.android.library`, `stayfocused.android.library.compose`, `stayfocused.android.feature` (adds compose, hilt, `:core:ui`, `:core:model`, `:core:data`), `stayfocused.android.hilt`, `stayfocused.android.room`, `stayfocused.jvm.library`.
- `compileSdk = 36`, `targetSdk = 36`, `minSdk = 26`, Java/Kotlin toolchain 17.
- `:app` (`com.dculus.stayfocused`) and `:kids` (`com.dculus.stayfocused.kids`): `@HiltAndroidApp` Application, single `MainActivity` with `enableEdgeToEdge()` that shows a placeholder text.
- `:core:model` and `:core:testing` are plain JVM/Android libraries with a placeholder class.
- `.gitignore` for Android/Gradle (keep `/.idea/`), plus `**/google-services.json`, `*.keystore`, `local.properties`, `.terraform/`.
- Root `README.md`: what the app is, how to build, the GPL-3.0 badge, and links to `AGENTS.md` and `docs/IMPLEMENTATION_PLAN.md`.

## Acceptance criteria
- [ ] `./gradlew assembleDebug` builds both APKs from a clean checkout with no `google-services.json`.
- [ ] Both apps install side by side and launch on API 26 and API 36 emulators.
- [ ] No `:feature:*` module depends on another `:feature:*` module (checked with `./gradlew :feature:home:dependencies` or a simple Gradle check).
- [ ] All versions live in the version catalog. No hard-coded versions in module build files.

## Implementation notes
- Use the Kotlin Compose compiler Gradle plugin (`org.jetbrains.kotlin.plugin.compose`), not `kotlinCompilerExtensionVersion`.
- Look up current stable versions with Context7 / official docs. Don't guess.
- Keep module build files tiny: plugins + namespace + dependencies.
