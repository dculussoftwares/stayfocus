## Scope
- Titles: "How much time?" / "When should it lock?" / "Lock for how long?" / "On for, off for" (or "Check your block" when `fromAi`).
- Limit: Per day / Per hour tabs + dial (`DialConfigs.Limit`). Cycle: "USE FOR" / "THEN LOCKED" tabs editing one dial with the matching config. Schedule: range presets (09:00–17:00 Work, 16:00–20:00 Study, 22:00–07:00 Night) + Custom (a themed time-range picker). Now: dial (`DialConfigs.Now`). Day chips M–S for every type except Now.
- Pure `BlockSummary.sentence(draft, appLabels)` and `BlockSummary.nameAndDescription(...)` ported **exactly** from the prototype `wizSummary` / `wizNext`.
- "Turn on block" saves an enabled `Block` (NOW sets `startedAt = now`), goes to the Block tab with that target selected, and shows the toast "{name} is on · {target}".
- An AI DRAFT banner slot (filled in M9-05).

## Acceptance criteria
- [ ] Unit tests reproduce the prototype's sentences for each type (≥ 12 cases, including "+N" app truncation and the day summaries).
- [ ] An end-to-end UI test creates each of the 4 types and finds it in the list.
