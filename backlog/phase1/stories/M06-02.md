## Scope
- Apply the google-services plugin only when `google-services.json` exists (convention plugin check). Firebase BoM dependencies in `:core:sync`.
- `FirebaseAvailability.isConfigured` (`FirebaseApp.getApps(context).isNotEmpty()`). When false, account, linking and cloud AI show "Not available in this build", and blocking works normally.
- **App Check client:** install the Play Integrity provider in release builds and the debug provider in debug/CI builds (the debug token comes from an env var or secret, never committed), in both apps, so that M7-01 can enforce App Check on Firestore and the callable Functions.
- `docs/FIREBASE_SETUP.md` for forks: point `infra/firebase` at your own project, or create `google-services.json` manually for local use.

## Acceptance criteria
- [ ] CI builds both with and without the config file.
- [ ] A unit test for the availability gate.
- [ ] Requests from a debug build carry an App Check token (checked in the App Check metrics or the emulator).
