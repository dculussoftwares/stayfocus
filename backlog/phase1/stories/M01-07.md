## Context
The dial is the signature control (Take a break and wizard step 3). Its maths is in the prototype `dialDown` and `dial` code; the README → *Interactions* summarises it.

## Scope
- Pure function in `:core:model`: `dialValueForAngle(angleDeg, config)`. The angle is clockwise from 12 o'clock, `value = round(angle/360 × max / step) × step`, clamped to `[step, max]`, and a raw 0 maps to `max`.
- Pure function `dialCenterLabel(value)`: `v<60 → "v"`; `v≥60 → "h"` or `"h:mm"`. Unit label is MINUTES / HOUR / HOURS.
- `RotaryDial(value, onValueChange, config, modifier)`: 240 dp. 60 ticks (every 6°; major every 5th tick; radius 76 for major and 82 for minor, both to 88). Ticks up to the value are lit lime, the rest `#33372F`. Progress ring at radius 100 with a knob at the value angle. The centre font is 54/44/36 sp for label length ≤2 / 3 / more. Dragging anywhere on the ring updates the value. Haptic tick on each value change.
- `DialPresets(config, value, onPick)` row using `dialLabel`.
- Accessibility: `progressBarRangeInfo` + `setProgress` semantics, so TalkBack users can change the value.
