## Context
Blocking must react within ~300 ms of a blocked app opening. Play policy: **do not set `isAccessibilityTool`**; request the minimum capabilities.

## Scope
- `ForegroundAppService : AccessibilityService` listening for `TYPE_WINDOW_STATE_CHANGED` only. Config XML: `canRetrieveWindowContent=false`, `notificationTimeout=100`, a description string that matches the disclosure.
- `ForegroundAppTracker` (Hilt singleton) exposing `StateFlow<ForegroundApp?>` (pkg + since). Filters: own package's block screen, `com.android.systemui`, active IMEs (`InputMethodManager.enabledInputMethodList`), windows that aren't activities (check `PackageManager.getActivityInfo` for the event class; ignore on failure), and consecutive duplicates.
- Screen on/off tracking (`ACTION_SCREEN_OFF` → foreground = null), so time isn't counted while the screen is off.
- `AccessibilityStatus.isEnabled(context)` via `Settings.Secure.ENABLED_ACCESSIBILITY_SERVICES`.
- Declare the service in the `:app` manifest (the `:kids` declaration comes in M8-03).

## Acceptance criteria
