## Scope
- Enable the AI Logic / Gemini APIs required by the Firebase AI Logic SDK (look up current API names in the docs).
- Extend the M7-01 App Check setup: enforce App Check on the AI Logic service, so only genuine app builds can call Gemini through the project.
- Restrict the Android API key(s) to the app packages and SHA certs and to the needed APIs (`google_apikeys_key`); set quota limits and budget alerts for Gemini usage.

## Acceptance criteria
- [ ] Applied from Actions; an AI request without App Check is rejected on dev.
