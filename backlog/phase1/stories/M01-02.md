## Context
Agents work in parallel, so CI is the single gate that keeps `main` healthy. The Definition of done command in the plan (§4) must run in CI.

## Scope
- Spotless with ktlint plus the Compose ktlint rules (`io.nlopez.compose.rules`), `.editorconfig`.
- detekt with a committed `config/detekt/detekt.yml` (Compose-friendly: allow `@Composable` function naming, raise LongParameterList for composables) and an empty baseline.
- Android Lint: `abortOnError = true`, `checkDependencies = true`, lint baseline only if needed.
- `.github/workflows/ci.yml` on `pull_request` and `push` to `main`: checkout, JDK 17 (temurin), `gradle/actions/setup-gradle` with cache, run `./gradlew spotlessCheck detekt lint testDebugUnitTest assembleDebug`, upload lint/test/detekt reports as artifacts, `concurrency` cancels superseded runs.
- `.github/ISSUE_TEMPLATE/story.md` that mirrors the story format of this backlog (for outside contributors). The CI workflow also runs on `pull_request`, for PRs from forks.

## Acceptance criteria
- [ ] A push to `main` with a ktlint violation fails CI; the fix-forward commit makes it pass.
- [ ] A clean run finishes in under ~10 minutes with a warm cache.
- [ ] The CI job is named `build` so it can be made a required check (M1-12).

## Out of scope
Release builds and signing (M10-03). Terraform workflows (M1-12, M1-13).
