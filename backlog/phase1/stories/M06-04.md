## Scope
- Credential Manager with `GetSignInWithGoogleOption` (the button flow) → Firebase `GoogleAuthProvider` credential. The web client ID comes from the `default_web_client_id` resource generated from the Terraform-provided config.
- Handle cancellation, no credentials, and a network error.
