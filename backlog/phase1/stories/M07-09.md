## Scope
- Kids Home: a persistent notification preview, today's total, the rules set by the parent (read-only from Firestore), and Unlink.
- Callable `unlinkDevice(deviceId)`: the caller must be the parent who owns it or the device's `childUid`. It deletes the device subtree completely (`firestore.recursiveDelete`), and when the child unlinks it sends the parent a push via the shared notify module (built in M8-05; until then, log only). The parent's Remote screen "Unlink" (M8-04) uses the same function.
- Child flow: Unlink → confirm → function → toast "Unlinked. {parent} has been notified." → back to the Link screen; the service stops. A child whose device doc disappears (unlinked by the parent, or the parent deleted their account) also resets to the Link screen.

## Acceptance criteria
- [ ] An emulator test shows no documents remain under the device and that a third party can't unlink.
- [ ] Manual test on dev for both directions.
