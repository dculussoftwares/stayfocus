## Context
The README describes per-app open sessions with a cooldown timer. Agreed semantics: the *use* window counts **foreground time only**; when it's used up, the app locks for *rest* minutes; the next open after that starts a new window. State is per (block, app).

## Scope
- Persist `CycleStateEntity` on every foreground stop and on every exhaustion, so the state survives restarts.
- Lock at the exact moment use runs out while the app is open.
- The block screen shows "Opens again in mm:ss".

## Acceptance criteria
- [ ] Device test: use 1 min / rest 2 min on two apps behaves independently per app.
- [ ] Leaving and returning within the window continues the same window (foreground only).
- [ ] Killing the app process mid-rest keeps the lock.
