## Context
Pure-Kotlin types shared by the evaluator, the database, the UI and the AI parser. Several formatters must reproduce the prototype's output exactly, because copy is final.

## Scope
- Types from plan §6: `Block`, `BlockType`, `LimitPeriod`, `BlockTarget`, `BlockSource`, `BreakSession`, `FocusSession`, `LockedApp(pkg, target, since)`, `TemporaryAllowance(pkg, until)`, `Permissions`, `LinkedDevice`, `TamperAlert`, `UnlockRequest`, `AppInfo(pkg, label)`, `DayUsage`, `AppUsage`.
- `DaysOfWeek` value class (bitmask Mon..Sun) with `contains(DayOfWeek)`, `ALL`, `WEEKDAYS`, `WEEKENDS`.
- `TimeRange(start: LocalTime, end: LocalTime)` with `crossesMidnight`, `contains(LocalTime)`, `parse("09:00–17:00")` (en dash) and `format()`.
- `DialConfig(max, step, presets)` and the `DialConfigs` constants from plan §6.
- Formatters ported from the prototype `<script>`: `formatMinutes` (`fmt` → "2h 27m" / "41m"), `mmss`, `hms`, `dialLabel` (`dlabel` → "15m" / "1h" / "1h30"), `durationLabel` (`nowLabel` → "45 min" / "1 h" / "1 h 30 min"), `daysSummary` ("every day" / "on weekdays" / "on Mon, Wed" / "no days").
- `KnownApps`: map from prototype ids (instagram, youtube, reddit, whatsapp, chrome, x, spotify, maps) to package names, plus the "social media" group. Used by templates (M4-01) and AI (M9).

## Acceptance criteria
- [ ] The module has no Android dependency (`stayfocused.jvm.library`).
- [ ] Table-driven unit tests cover every formatter, using the prototype's outputs as expected values (≥ 5 cases each, including 0, 59, 60, 61, 90, 480).
- [ ] `TimeRange.contains` is tested for normal, overnight (22:00–07:00) and boundary minutes (the start is inclusive and the end is exclusive).
