## Scope
- "Blocking on" target cards: This phone (ME) + each linked device (from `LinkedDevicesRepository`; empty until M7). Each card shows a count "N ACTIVE"; the selected card has a lime border.
- A big lime "New block" button with "on {target}" → wizard.
- An AI box toggle that shows the AI describe panel (feature-flagged off until M9-05).
- Segmented tabs Blocks / All apps (All apps is M4-05). The Blocks list uses the same row as Home, plus an empty state.
- 4 template cards (Mindful scrolling, Study time, Social limit, Bedtime) → wizard at step 3, prefilled as in the prototype `templates`. Template app ids map to installed packages via `KnownApps`; if none are installed, open at step 2.

- [ ] ViewModel tests for the target switch and the template prefill mapping.
