## Context
v5 Home shows "{n} min under your 3h goal" / "{n} min over your 3h goal" (prototype line 647). The app has no goal today. v5 has no editor, so the goal is a stored value with a default (V5_SPEC §8 question 1).

## Scope
- DataStore key `screenTimeGoalMins` (default 180) in the settings repository, exposed as `Flow<Int>`, with a setter for a later editor.
- Pure function in `:core:model`: `goalNote(todayMins, goalMins)` → `Under(n)` / `Over(n)` / `OnGoal`, tested.

## Out of scope
Home UI (M12-07), any editor UI.

## Acceptance criteria
- [ ] Unit tests for the repository (fake DataStore) and `goalNote`.
- [ ] Existing settings keep their values (no migration needed; test that a store without the key reads 180).
