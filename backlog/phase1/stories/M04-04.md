## Scope
- Tapping a block row opens the wizard in edit mode at step 3 with its values; the CTA is "Save changes".
- Delete through a confirm bottom sheet (no system dialog). Proposed copy: "Delete this block?" / "Delete" / "Keep it". Flag it for design review in the PR.
- Toggles on Home and the Block tab stay in sync (same repository flow).

## Acceptance criteria
- [ ] Editing keeps the block id and the `createdAt`.
- [ ] Deleting removes the cycle state and the join rows.
