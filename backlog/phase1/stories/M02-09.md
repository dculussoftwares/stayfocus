## Scope
- Verify and fix: reboot (the accessibility service rebinds; the engine restores state), process death, force-stop recovery messaging, split-screen/multi-window and picture-in-picture (block the PiP app's window or close it), app updates of blocked apps, and the device locale changing.
- Expose `EngineHealth` (service bound, last event time) for permission health (M5-03, M6-05).
- A manual test matrix in `docs/qa/blocking-matrix.md`: Pixel API 36, API 26 emulator, Samsung, Xiaomi.

## Acceptance criteria
- [ ] The matrix is filled in with results; every blocker found is fixed or filed as an issue.
