## Context
This is a public repo with user-facing permissions (Accessibility, usage data) and cloud infrastructure. Scan code, dependencies, workflows and IaC continuously.

## Scope
- **CodeQL** (`.github/workflows/codeql.yml`) on PRs, on `main` and weekly, for `java-kotlin` (build mode: autobuild or manual Gradle), `javascript-typescript` (Functions) and `actions`.
- **Dependency review** (`actions/dependency-review-action`) on PRs: fail on high-severity vulnerabilities and on licences incompatible with GPL-3.0.
- **Dependabot** (`.github/dependabot.yml`): Gradle, npm (`firebase/functions`), GitHub Actions (SHA-pinned updates), Terraform and pre-commit; weekly, grouped minor/patch updates. Dependabot PRs go through the same CI + CodeRabbit gate.
- **gitleaks** CI job on PRs (full history on `main` weekly).
- **IaC scan**: Trivy config scan (or Checkov) on `infra/**` with SARIF upload, and **tflint** with the google ruleset.
- **Workflow audit**: zizmor on `.github/workflows/**` (template injection, excessive permissions, unpinned actions).
- Turn on GitHub secret scanning + push protection and Dependabot alerts **through Terraform** in `infra/github` (`github_repository.security_and_analysis`, `vulnerability_alerts`). This needs the M1-12 App permissions.
- Add the blocking scans (dependency review, gitleaks, Trivy high/critical, zizmor high) to the `ci-pass` aggregate or to the ruleset's required checks; CodeQL alerts are reviewed in the Security tab.

## Acceptance criteria
- [ ] A PR adding a dependency with a known critical CVE fails dependency review.
- [ ] A PR adding a public Firestore rule or an over-privileged IAM binding is flagged by the IaC scan or CodeRabbit.
- [ ] Secret scanning and push protection are enabled, and the Terraform plan shows them as managed.
