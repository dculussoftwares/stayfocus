## Context

## Scope
- `PillTabBar` in `core.ui.v5.components` (V5_SPEC §4): left/right 14 dp, bottom 22 dp + navigation-bar inset, padding 5, r32, ink @ .92 with blur on API 31+, shadow; tabs h50 r25; selected white/ink, others `onInkMuted`; 15/600; `Role.Tab`.
- Replace the v2 `SfTabBar` in the `:app` scaffold; content draws under the bar and gets bottom padding = bar height + gap + inset (expose it via a `LocalTabBarPadding` so tab screens can pad their lists).
- Tab label strings: "Home", "Blocks", "Family", "Insights".
- Host the v5 toast (M11-07) at the scaffold level so screens can show toasts above the bar.
- Update Maestro flows that tap tab labels (`BLOCK`, `DEVICES`, `INSIGHTS` → `Blocks`, `Family`, `Insights`).
