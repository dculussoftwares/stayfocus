## Scope
- `StayFocusedDatabase` v1 with schema export to `core/data/schemas/` (committed).
- Entities: `BlockEntity` (all `Block` fields; target as `me` or a deviceId string), `BlockAppEntity(blockId, pkg)` join table, `LockedAppEntity(pkg, target, since)`, `CycleStateEntity(blockId, pkg, usedMs, windowStartedAt, lockedUntil)`, `BlockEventEntity(id, pkg, blockId?, reason, at)`, `UsageDayEntity(date, pkg, foregroundMs, opens)`, `UsageHourEntity(date, hour, foregroundMs, unlocks)`, `UsageTotalsEntity(date, totalMs, opens, unlocks)`.
- DAOs with `Flow` queries: blocks by target, enabled blocks containing a pkg, locked apps, cycle state by key, today's block-event count, usage by date range.
- TypeConverters for `Instant`, `LocalDate`, `LocalTime`, enums and `DaysOfWeek`. Entity↔model mappers. Hilt `DatabaseModule`.
- `MigrationTestHelper` wired up, so future migrations have a test harness.

## Acceptance criteria
- [ ] Robolectric DAO tests: insert/update/delete a block with its apps; query by target and by pkg; cascade delete removes the join rows.
- [ ] Schema JSON v1 is committed and CI fails if it changes without a version bump.
