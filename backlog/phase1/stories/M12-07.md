## Context
References: `05-home.png` (idle) and `07-break-running.png`; prototype 83–155 and values 601–654; V5_SPEC §5 Home. The break engine, usage data and linked devices are shipped.

## Scope
- Header (avatar initial → Account, date, "Hi, {first name}", bell with attention badge; hidden when no phone is linked).
- Violet hero: "Screen time today", `DotMatrixText` h:mm, goal note from M12-01, `DotGrid` of today's hours (current hour highlighted), glass tiles "Blocked"/"times"/"Apps stopped today" and "Most used"/"min"/{app} → Insights. Add blocked count and the most-used app to `HomeViewModel` if they're missing (tests first).
- "Block apps" tile (two tilted app tiles from the active blocks; "Active blocks" / "{n} on this phone") → wizard for this phone.
- "Take a break" tile: idle with `BreakArt` → sheet (the shipped sheet until M12-08); running "On a\nbreak" + mm:ss + "Tap to end early" → end + toast "Break ended".
- AI pill "Describe a block in your words" → Describe with AI.
- One pink child card per linked phone (name, online pill, Today / Using now / Battery, request row "Wants {n} more min on {app}" + "Review") → child screen; or the white "Link a child's phone" row → scan (shipped sign-in gate applies).
- Extras (M13): anything the shipped Home shows that isn't above (e.g. average marker, launches/unlocks stats, active block toggles) moves to its v5-extra place per the extras rule.

- [ ] Matches the reference PNG(s) named above: layout, spacing, type, colours, radii. Put your Roborazzi render next to the reference in the PR and list every remaining difference with a reason.

- [ ] Shipped elements v5 doesn't show follow the extras rule (V5_SPEC §2): still working, v5-styled, marked `// v5-extra: <M13 id>`, listed in the PR.
- [ ] Screen wrapped in `V5Screen`; no v2 tokens or components left in the migrated Composables.
