## Context
First story of the v5 redesign. Read `docs/design/V5_SPEC.md` §0–§3 completely. The v5 design system lives **next to** the v2 one in the package `com.dculus.stayfocused.core.ui.v5`; don't change v2 files (`core.ui.theme`, `core.ui.components`).

## Scope
- `v5.theme.V5Colors` (every colour in V5_SPEC §3, semantic names), `V5Gradients` (each named gradient as a `Brush` factory that takes the drawn size, so CSS `radial-gradient(W% H% at X% Y%)` maps to an elliptical radial brush), `V5Type` (the type scale), `V5Shapes`, `V5Spacing`, exposed through `CompositionLocal`s and a `V5Theme` object (`V5Theme.colors`, `.type`, …).
- Bundle **Urbanist** (Google Fonts, SIL OFL 1.1, variable `wght` 100–900) in `core/ui/src/main/res/font/`; licence text in `docs/licenses/`; add a row to `docs/FONTS.md`. No download at runtime.
- `V5Theme { }` composable: provides the locals and a light Material 3 `colorScheme` + `Typography` mapped from the tokens (for any M3 widget used inside).
- `V5Screen(darkContent: Boolean, background: Brush? = null) { }`: `V5Theme` + background (`#EDEDEB` by default) + edge-to-edge insets helpers + status/navigation bar icon colour (light icons when `darkContent`).
- `GrainOverlay` modifier: deterministic noise tile (fixed seed, 180 × 180, white, alpha .16, `BlendMode.Softlight`), generated once and cached; `Modifier.glow(gradient, shape)` that draws gradient + grain and clips.
- `V5Showcase` preview screen (colours, type scale, every gradient with grain) + Roborazzi test.

## Out of scope
Components (M11-02…08), any screen change.

## Acceptance criteria
- [ ] Tokens match V5_SPEC §3 exactly (unit test asserts the hex values of the semantic tokens).
- [ ] Urbanist renders in previews and on device at weights 200, 300, 400, 500, 600, 700; licence committed; `docs/FONTS.md` updated.
- [ ] Grain is deterministic: two Roborazzi runs give identical images.
- [ ] `V5Screen` sets status-bar icons correctly on API 26 and API 36 (light and dark content).
- [ ] No change to existing screens or their baselines.
