## Scope
- Preferences DataStore `settings`: `onboardingComplete`, `accountSkipped`, `breakSession` (startedAt/endsAt/lengthMins), `focusSession`, `accessibilityConsentAt`, `aiEnabled`.
- Repository interfaces + implementations: `BlockRepository` (observe by target, get, upsert, setEnabled, delete), `LockedAppsRepository`, `BreakRepository` (observe, start(mins), end()), `SettingsRepository`.
- `:core:testing`: `MainDispatcherRule`, `TestClock`, and in-memory fakes of every repository for ViewModel tests.
- Wire `AppStartViewModel` (M1-09) to `onboardingComplete`.

## Acceptance criteria
- [ ] Unit tests (Turbine) for every repository's flows.
- [ ] Fakes are behaviour-equivalent to the real implementations (one shared contract test per repository runs against both).
