## Context
Every screen uses v5. Remove v2 so there's one design system.

## Scope
- Delete v2 tokens, theme and components (`core.ui.theme`, `core.ui.components`: RotaryDial, ScreenTimeGauge, LedBarChart, Panels, SfTabBar, SfToggle, SfToast, SfBottomSheet, …) and their baselines; delete the v2 fonts (Space Grotesk, Plus Jakarta Sans, Geist Mono) and `scripts/dev/fetch-fonts.sh` + the font-asset loading if nothing uses them.
- Move `core.ui.v5.*` to the final packages (`core.ui.theme`, `core.ui.components`, …) in one mechanical change; provide `V5Theme` (renamed `StayFocusedTheme`) at the app roots; `V5Screen` keeps per-screen background and bar colours.
- Remove dial maths from `:core:model` if unused.
- Docs: `docs/FONTS.md`, `docs/IMPLEMENTATION_PLAN.md` (design section), `AGENTS.md`/`CLAUDE.md` design pointers → `docs/design/V5_SPEC.md`; mark `design_handoff_stay_focused_phase1/` as historical.

## Acceptance criteria
- [ ] `grep -rn "core.ui.v5\|RotaryDial\|LedBarChart\|SfTabBar" --include=*.kt` finds nothing.
- [ ] `./gradlew ciCheck` green; screenshots identical to before the move except deleted v2 previews.
- [ ] APK size reported before/after in the PR.
