## Scope
- The prod project via `infra/bootstrap`, and the HCP workspace `stayfocus-firebase-prod`. `infra/firebase` is applied to prod through a protected GitHub Environment `prod` (manual approval).
- Prod release SHA fingerprints (the Play App Signing key). Budget alerts and Cloud Monitoring alert policies (function error rate, FCM failures) as Terraform resources.
