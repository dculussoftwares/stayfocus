## Scope
- `<queries>` with the `MAIN`/`LAUNCHER` intent in the `:core:usage` manifest. **No `QUERY_ALL_PACKAGES`** (Play policy).
- `InstalledAppsRepository.observeLaunchableApps(): Flow<List<AppInfo>>`: `queryIntentActivities`, dedupe by pkg, exclude own apps, sort by label (locale-aware), refresh on `PACKAGE_ADDED/REMOVED/CHANGED`.
- App icon loading: a Coil `Fetcher` for `package:` URIs with a memory cache; `AppIcon(pkg)` in `:core:ui` uses it, with the letter-tile fallback.

## Acceptance criteria
- [ ] Robolectric test with shadowed `PackageManager` entries.
- [ ] Installing or uninstalling an app updates the flow without restarting the app.
- [ ] The merged manifest contains no `QUERY_ALL_PACKAGES`.
