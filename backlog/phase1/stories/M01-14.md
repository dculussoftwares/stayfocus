## Context
Catch the cheap problems before they reach a PR: formatting, leaked secrets, broken YAML or Terraform. Agents and humans run the same hooks, and CI re-runs them (`pre-commit` job in M1-02), so skipping them locally doesn't get anything past the gate.

## Scope
- The [`pre-commit`](https://pre-commit.com) framework with `.pre-commit-config.yaml`; hook versions are pinned (and updated by Dependabot/`pre-commit autoupdate` in M1-15).
- **pre-commit stage** (fast, staged files only; target < 10 s):
  - hygiene: `trailing-whitespace`, `end-of-file-fixer`, `check-yaml`, `check-json`, `check-merge-conflict`, `check-added-large-files` (500 KB), `mixed-line-ending`;
  - **gitleaks** (secret scan; public repo);
  - **ktlint** on staged `*.kt`/`*.kts` (same version and rules as Spotless);
  - `terraform fmt` + `terraform validate` + **tflint** for `infra/**`;
  - **actionlint** for `.github/workflows/**`;
  - `python3 scripts/backlog/waves.py --check` when `backlog/**` changes;
  - a guard that blocks committing `google-services.json`, `*.jks`/`*.keystore`, `*.tfstate` and `.env*`.
- **pre-push stage** (slower): `./gradlew spotlessCheck detekt testDebugUnitTest` (configuration cache on).
- `scripts/dev/setup-hooks.sh`: installs pre-commit (pipx/brew), then `pre-commit install --hook-type pre-commit --hook-type pre-push`. Document it in `README.md`, `CLAUDE.md` and `AGENTS.md` (agents run it once per clone/worktree).

## Acceptance criteria
- [ ] Committing a file containing a fake AWS key or GitHub token is blocked by gitleaks.
- [ ] A badly formatted Kotlin file or Terraform file is blocked at commit; a failing unit test is blocked at push.
- [ ] `pre-commit run --all-files` passes on `main`, and the CI `pre-commit` job is enabled.
