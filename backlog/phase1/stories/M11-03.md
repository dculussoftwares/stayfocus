## Context

## Scope
- `V5Card` (white or `surfaceRaised`, radius 28–36 parameter, padding, optional click with ripple clipped to the shape, soft ink shadow).
- `GlowCard(gradient, radius)` (gradient + grain, clips children, white content colour).
- `GlassTile` (white .18 fill, 1 dp white .3 border, blur 16 on API 31+, plain fill below).
- `ActionTile` (204 dp, r36, title top-left 20/500, 46 dp white "+" circle top-right, bottom content slot, optional gradient background).

## Acceptance criteria
- [ ] Previews + Roborazzi tests for each card on white and on gradients; API 26 fallback for blur covered by a test variant.
- [ ] Click ripple respects the card shape; cards are a single TalkBack node with a merged label when clickable.
