## Context
The look is "dark instrument panel with a lime accent". All tokens are in the handoff README → *Design tokens (v2)*. Features must only use theme tokens (plan §5).

## Scope
- `StayFocusedColors` with every colour role from the handoff table (background, panel, panel gradient start/end, track, hairline variants .06/.08/.10/.14, text, secondary, tertiary, accent, accentHover, alert, alertText, warning, appTints[7]), exposed through a `CompositionLocal`.
- Map them into a dark Material 3 `ColorScheme` so stock components look right.
- Typography: Clash Display 600 (display), Satoshi 400/500/700/800 (body), Geist Mono 500/600/700 (labels and numbers). Define named roles: `displayXL 54`, `displayL 44`, `displayM 38`, `display 34`, `displayS 26`, `title 22`, `bodyL 16`, `body 14`, `bodyS 12.5`, `label 11 mono uppercase +0.1em`, `labelS 10`, `numeric` 16–60 mono. Letter-spacing per the handoff.
- `StayFocusedShapes` (chip 8, input/button 16, card 20, hero 28, sheet 32, tabBar 24) and `StayFocusedSpacing` (screen 18; gaps 6/8/10/12/14/16/22).
- `StayFocusedTheme { }` wraps `MaterialTheme` and provides the locals. Dark only. Window background `#0E0F0D` and splash-screen theme, so there's no white flash.
- **Font licence check:** read the Fontshare (ITF Free Font License) terms for Clash Display and Satoshi and record whether the font files may be redistributed in a public GPL-3.0 repo. Write the result in `docs/FONTS.md`. If redistribution isn't allowed, keep the font files out of git, document the fetch step, and fall back to an OFL substitute so the build still works. Geist Mono is OFL and can be bundled.
- A debug-only `ThemeShowcase` composable preview that renders all tokens.

## Acceptance criteria
- [ ] Token values match the handoff table exactly (unit test asserting the hex values).
- [ ] A Roborazzi screenshot of `ThemeShowcase` is committed.
- [ ] `docs/FONTS.md` states the licence finding with a link to the source.
