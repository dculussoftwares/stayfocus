## Scope
- The `firebase-ai` SDK, current Gemini Flash model (check the docs), `responseMimeType = application/json` + `responseSchema`, a system instruction adapted from `AI_SYS`, an 8 s timeout.
- `AiBlockBuilder.build(sentence)`: Gemini → normalise; on any error, offline or Firebase not configured → fallback parser. Only the sentence is sent. **No account required.**
- An eval script/test (manual or nightly, not per-PR) that runs the M9-02 fixture against the live model and reports accuracy.

## Acceptance criteria
- [ ] Unit tests with a fake model for timeout, malformed JSON and the fallback path.
- [ ] The eval accuracy is reported in the PR.
