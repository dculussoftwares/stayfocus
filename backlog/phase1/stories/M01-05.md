## Context
These building blocks appear on almost every screen. Open the prototype and inspect each element. Its inline styles are the spec.

## Scope
- `PrimaryButton` (h56, r16, lime, ink 16/800, pressed = accentHover, disabled), `WhiteButton` (the "+ New block" style), `OutlineButton`, `GhostButton`, all with an optional leading icon and a loading state (spinner + mono label).
- `Panel` (gradient #1A1C17→#141611, r20, hairline border) and `HeroCard` (r28).
- `SfToggle`: track lime/#262922, knob ink/#6E7367, 150 ms animation, `Role.Switch`.
- `TypeChip` (LIM/CYC/HRS/NOW with the `CHIP` colours; dimmed when the block is off), `SelectChip` (prototype `sel()`), `SegmentedTabs` (prototype `seg()`), `DayChips` (M T W T F S S).
- `LedDot` with an optional glow and a pulse animation (1.6–2 s loop).
- `MonoLabel`, `SectionHeader`, `StatTile`.
- `AppIcon(pkg)`: loads the launcher icon (via the catalog from M3-02 later; for now takes a `Drawable?`) and falls back to the letter tile with a tint from `appTints`.
- `SfTextField`: r16, label, inline error text in alertText, password variant with a show/hide toggle.

## Acceptance criteria
- [ ] Every component has a `@Preview` and a Roborazzi screenshot test.
- [ ] Touch targets are ≥ 48 dp; toggles and chips expose correct semantics for TalkBack.
- [ ] No hard-coded colours; only theme tokens.
